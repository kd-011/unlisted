# unlisted docs

- [install.md](install.md): install routes: release binary, `go install`, from a checkout.

- [limitations.md](limitations.md): what it cannot see or do, and the roadmap.
- [reference.md](reference.md): finding types, discovery sources, flags and exit codes.
- [registry.md](registry.md): the `registry.yml` format and its fields.

- [demo.png](demo.png) and [demo-hero.png](demo-hero.png): the full demo report and the README hero image, made by `make screenshot`.
